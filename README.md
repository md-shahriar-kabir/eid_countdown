# ⚙️ Installation & Setup

## Clone the repository

```bash
git clone https://github.com/your-username/eid-countdown.git
```

## Navigate to project folder

```bash
cd eid-countdown
```

## Install dependencies

```bash
npm install
```

## Run the development server

```bash
npm run dev
```

## Open in browser

```bash
http://localhost:3000
```

---

# 🧠 How It Works

The app calculates the remaining time between the current date and the target Eid date using JavaScript Date APIs. The countdown updates automatically every second without reloading the page.
